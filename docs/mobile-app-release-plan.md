# TTWITTUN 모바일 앱 전환·배포 로드맵

작성 기준: 2026-08-31

## 현재 결론
TTWITTUN은 웹 기반 코스 탐색 서비스에서 **개인 러닝 기록 플랫폼**으로 확장 중이다. 현재 자유 러닝, 코스 러닝, GPS 거리/시간, 현재·평균·최고 페이스, 1km 자동랩, 스플릿, GPS 궤적, 로컬 임시저장/복구, MY 기록 저장까지 웹 버전에 구현되어 있다.

1차 앱 전략은 기존 Next.js + Supabase 구조를 최대한 재사용하는 **Capacitor 기반 하이브리드 앱**이다. 앱 전환의 핵심 목적은 UI 재작성보다 백그라운드 GPS와 화면 잠금 상태 기록 신뢰도를 확보하는 것이다.

## 앱 식별 정보
- 공식 서비스명: `TTWITTUN`
- iOS Bundle ID: `com.ttwittun.korea`
- Android applicationId: `com.ttwittun.korea`
- 현재 웹 운영 주소: 기존 호환을 위해 `https://runart-korea.vercel.app` 유지
- 정식 도메인은 TTWITTUN 브랜드 기준으로 추후 전환

## Phase 0 — 현재 웹 안정화
- 자유 러닝/코스 러닝 실제 야외 테스트
- 5km 거리 오차 검증
- 1km 자동랩/스플릿 검증
- 현재/평균/최고 페이스 검증
- 일시정지/재시작 검증
- 브라우저 강제 종료 후 이어달리기 복구
- MY 개인 기록 저장/조회
- 코스 탐색 → 출발 준비 → LIVE RUN → 기록 → RUN + EAT 흐름 유지

## Phase 1 — Capacitor 내부 테스트 앱
다음 조건을 만족하면 실기기용 iOS/Android 프로젝트를 생성한다.
- 화면 켠 상태 5km 기록 안정
- 자유 러닝과 코스 러닝 저장 정상
- GPS 거리 오차 목표 ±5% 이내
- 자동랩 누락 없음
- 임시저장/복구 정상
- 인증/RLS 안정

이 단계에서는 스토어 공개 없이 개발자 기기에 직접 설치해 테스트한다.

## Phase 2 — 네이티브 GPS 전환
- iOS/Android 백그라운드 위치 권한
- 화면 잠금 상태 GPS 지속 기록
- 앱 라이프사이클 기반 러닝 세션 복구
- 네이티브 로컬 저장소
- 위치 권한 설정 화면 연결
- 음성 1km 랩 안내
- 지도 앱 딥링크

## Phase 3 — TestFlight / Google Play 내부 테스트
- iPhone / Android 실기기 여러 모델 테스트
- 5km 이상 실제 러닝 반복 테스트
- 화면 잠금 10분 이상
- 통화/카카오톡/카메라 등 다른 앱 전환 후 복귀
- 저전력 모드 / 배터리 최적화 상태
- 네트워크 단절 후 저장 복구
- 기록 중복/누락 여부 확인

## Phase 4 — 정식 스토어 제출
정식 출시 기준은 기능 수가 아니라 **개인 러닝 기록 신뢰도**다.

권장 최소 기준:
- 서로 다른 기기 3대 이상
- 5km 이상 실제 러닝 10회 이상
- 화면 켬/잠금/앱 전환 포함
- 거리 오차 사용 가능 범위 유지
- 기록 누락/중복 저장 없음
- 앱 재실행 후 러닝 복구 가능
- 개인정보처리방침 및 위치정보 사용 목적 고지
- 계정 삭제 / 러닝 기록 삭제 기능
