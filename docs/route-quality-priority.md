# RUNART KOREA route quality priority

Updated: 2026-09-01

## 목적

등록 거리(`distance_km`)와 현재 `route_geojson` LineString의 직선 구간 합산 길이를 비교해, 현장 테스트 전에 수정 우선순위를 정한다.

> 주의: 이 값은 도로/보행 네트워크를 따라 계산한 실제 주행거리가 아니라 현재 저장된 waypoint polyline 길이다. 따라서 오차가 크다는 것은 '코스 자체가 틀렸다'기보다 저장된 선형이 너무 거칠거나 반복/왕복 구조가 잘못 표현되었을 가능성이 높다는 뜻이다.

## 품질 등급

- A: 거리 오차 < 10% — 현장 검증 우선 후보
- B: 10% 이상 25% 미만 — 현장 검증 가능, 지도 경로 보완 권장
- C: 25% 이상 50% 미만 — 추천 노출은 가능하나 근사 경로 표기 필요
- D: 50% 이상 — 경로 재구성 우선. 검증 배지 금지

## UI 표시 원칙

- `verified=true`: `✓ 현장/경로 검증`
- `data_quality=official`, verified=false: `공식정보 기반 · 경로 확인 필요`
- community 또는 근사 waypoint: `추천/근사 경로`
- C/D 등급은 UI에서 `근사 경로` 또는 `경로 보완 중` 표기를 우선 적용한다.

## 운영 원칙

1. 거리 숫자만 맞추기 위해 좌표를 임의로 늘리지 않는다.
2. 공식 GPX가 있으면 GPX를 최우선으로 교체한다.
3. 공식 GPX가 없으면 실제 명칭이 있는 POI/교량/진입점으로 waypoint를 재구성한다.
4. 왕복 코스는 반환점과 복귀 선형이 저장 데이터에 명확히 반영되어야 한다.
5. GPS 아트는 모양과 실제 주행 가능성을 모두 확인하기 전까지 verified=false를 유지한다.
6. 현장 테스트 결과와 실제 GPS track이 확보되면 기존 근사 route를 실제 track 기반으로 개선한다.
