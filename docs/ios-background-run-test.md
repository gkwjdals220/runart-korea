# iOS 백그라운드 러닝 검수

실제 iPhone(iOS 16.1 이상)에서 아래 순서로 확인합니다.

1. TTWITTUN을 새로 설치하고 자유 러닝을 시작한다.
2. 위치 권한을 허용하고 100m 이상 이동해 거리와 페이스가 갱신되는지 확인한다.
3. 홈 화면으로 나간 뒤 2~3분 이동하고 앱으로 돌아와 거리와 경로가 이어지는지 확인한다.
4. 화면을 잠가 Live Activity에 거리, 시간, 페이스가 표시되는지 확인한다.
5. 지원 기기에서는 Dynamic Island를 길게 눌러 확장 화면도 확인한다.
6. 일시정지 중 거리가 늘지 않는지, 다시 시작 후 이어지는지 확인한다.
7. 종료 후 위치 사용 표시와 Live Activity가 종료되고 기록이 MY에 저장되는지 확인한다.

Live Activity가 보이지 않으면 iPhone의 `설정 → TTWITTUN → Live Activities`가 켜져 있는지 확인합니다.
