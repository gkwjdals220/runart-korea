# TTWITTUN LIVE RUN 현장 테스트 체크리스트

## 목적
모바일 앱 래핑 전, 현재 웹 기반 LIVE RUN의 GPS 기록 신뢰도와 개인 기록 측정 기능을 실제 러닝에서 확인한다.

## 권장 테스트 순서
1. 자유 러닝 500m 도보 테스트
2. 자유 러닝 1~2km 짧은 러닝 테스트
3. 코스 러닝 5km 실제 테스트
4. 화면 잠금/앱 전환을 포함한 5km 테스트
5. 강제 종료 후 이어달리기 복구 테스트

## 반드시 확인할 항목
- 러닝 시작 직후 GPS 권한 및 정확도 표시
- 거리 증가가 실제 이동과 유사한지
- 현재 페이스가 이동 상황에 맞게 반응하는지
- 평균 페이스가 종료 결과와 일치하는지
- 최고 페이스가 비정상적인 순간 GPS 튐으로 과도하게 빠르게 기록되지 않는지
- 1km 통과 시 자동랩이 생성되는지
- 각 스플릿의 랩타임/페이스가 비교 기기와 유사한지
- 일시정지 중 거리가 증가하지 않는지
- 다시 시작 직후 큰 GPS 점프가 거리로 합산되지 않는지
- 화면을 잠갔다가 복귀했을 때 기록 화면이 정상인지
- 브라우저를 강제 종료 후 다시 열었을 때 `이어달리기 복구` 카드가 나타나는지
- 복구 시 시간/거리/GPS 포인트/스플릿이 유지되는지
- 복구 직후 자동 기록이 아니라 일시정지 상태인지
- 자유 러닝 종료 후 `runart_live_runs`에 `run_mode='free'`로 저장되는지
- 코스 러닝은 `run_mode='course'`와 course_id가 함께 저장되는지
- 로그인 사용자는 MY에서 기록과 최고 페이스가 조회되는지
- 개별 기록 상세에서 GPS 궤적과 1km 스플릿이 조회되는지

## 허용 오차 기준
- 5km 기준 거리 오차: 우선 ±5% 이내 목표
- 1km 스플릿 오차: 비교 기기 대비 ±10초 이내 권장
- GPS 순간 정확도: 대부분 30m 이내 권장
- 80m 초과 저정확도 포인트는 거리 계산에서 제외되는 흐름 유지
- 화면 복귀 직후 위치 점프가 거리로 합산되면 안 됨

## 개인 기록 기능 GO 기준
- 자유 러닝 시작/종료가 별도 코스 없이 정상 작동
- 현재/평균/최고 페이스가 정상 표시
- 1km 자동랩이 누락 없이 생성
- 종료 후 거리/시간/평균페이스/최고페이스/스플릿 저장
- MY에서 자유 러닝과 코스 러닝이 함께 조회

## 앱 전환 GO 기준
아래가 충족되면 Capacitor 기반 iOS/Android 실기기 베타로 진행한다.
- 일반 화면 켜짐 상태 5km 완주 기록이 안정적
- 일시정지/재시작이 안정적
- 로컬 임시저장/복구가 정상
- 서버 저장 및 MY 조회 정상
- 지도/출발 준비/RUN+EAT 주요 웹 플로우가 모바일에서 안정적
- 자유 러닝 개인 기록 기능이 안정적

## 앱 전환 후 네이티브로 교체할 부분
- 백그라운드 위치 추적
- 화면 잠금 상태의 GPS 지속 기록
- 앱 라이프사이클 기반 러닝 세션 복구
- 위치 권한 안내 및 설정 이동
- 로컬 네이티브 저장소
- 음성 랩 안내
- 푸시 알림/딥링크
- 향후 Apple Health / Garmin 등 외부 기록 연동 검토

## 정식 스토어 제출 전 필수
- iOS TestFlight 실제 5km 테스트
- Android 내부 테스트 실제 5km 테스트
- 화면 잠금 10분 이상 테스트
- 통화/카카오톡/카메라 등 다른 앱 전환 후 복귀 테스트
- 저전력 모드/배터리 최적화 상황 테스트
- 네트워크 단절 후 복귀 및 기록 저장 테스트
- 개인정보처리방침 및 위치정보 사용 목적 문구 확정

## 현재 결론
TTWITTUN 웹은 코스 탐색 서비스에서 개인 러닝 기록 플랫폼으로 확장되었고, 현장 GPS 검증을 통과하면 모바일 앱 실기기 베타 단계로 전환한다.
