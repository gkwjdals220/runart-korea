# RUNART LIVE RUN 현장 테스트 체크리스트

## 목적
모바일 앱 래핑 전, 현재 웹 기반 `/run/[id]`의 GPS 기록 신뢰도와 복구 동작을 실제 러닝에서 확인한다.

## 권장 테스트 순서
1. 500m 도보 테스트
2. 1~2km 짧은 러닝 테스트
3. 5km 실제 코스 테스트
4. 화면 잠금/앱 전환을 포함한 5km 테스트

## 반드시 확인할 항목
- 러닝 시작 직후 GPS 권한 및 정확도 표시
- 거리 증가가 실제 이동과 유사한지
- 일시정지 중 거리가 증가하지 않는지
- 다시 시작 직후 큰 GPS 점프가 거리로 합산되지 않는지
- 화면을 잠갔다가 복귀했을 때 기록 화면이 정상인지
- 브라우저를 강제 종료 후 다시 열었을 때 `이어달리기 복구` 카드가 나타나는지
- 복구 시 시간/거리/GPS 포인트가 유지되는지
- 복구 직후 자동 기록이 아니라 일시정지 상태인지
- 러닝 종료 후 `runart_live_runs`에 기록이 저장되는지
- 로그인 사용자는 MY에서 기록이 조회되는지
- 크루 사용자는 크루 로그/참가자 기록이 정상 생성되는지

## 허용 오차 기준
- 5km 기준 거리 오차: 우선 ±5% 이내 목표
- GPS 순간 정확도: 대부분 30m 이내 권장
- 80m 초과 저정확도 포인트는 거리 계산에서 사실상 제외되는 흐름 유지
- 화면 복귀 직후 위치 점프가 거리로 합산되면 안 됨

## 앱 전환 GO 기준
아래가 충족되면 Capacitor 기반 iOS/Android 프로젝트 생성을 시작한다.
- 일반 화면 켜짐 상태 5km 완주 기록이 안정적
- 일시정지/재시작이 안정적
- 로컬 임시저장/복구가 정상
- 서버 저장 및 MY 조회 정상
- 지도/출발 준비/RUN+EAT 주요 웹 플로우가 모바일에서 안정적

## 앱 전환 후 네이티브로 교체할 부분
- 백그라운드 위치 추적
- 화면 잠금 상태의 GPS 지속 기록
- 앱 라이프사이클 기반 러닝 세션 복구
- 위치 권한 안내 및 설정 이동
- 필요 시 로컬 네이티브 저장소
- 푸시 알림/딥링크

## 정식 스토어 제출 전 필수
- iOS TestFlight 실제 5km 테스트
- Android 내부 테스트 실제 5km 테스트
- 화면 잠금 10분 이상 테스트
- 통화/카카오톡/카메라 등 다른 앱 전환 후 복귀 테스트
- 저전력 모드/배터리 최적화 상황 테스트
- 네트워크 단절 후 복귀 및 기록 저장 테스트
- 개인정보처리방침 및 위치정보 사용 목적 문구 확정

## 현재 결론
웹 기능은 앱 전환 준비 단계에 진입했다. 앱스토어/구글플레이 제출보다 먼저 실제 5km 현장 테스트를 1회 이상 통과시키는 것을 릴리스 게이트로 사용한다.
